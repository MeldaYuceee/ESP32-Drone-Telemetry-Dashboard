# ESP32-Drone-Telemetry-Dashboard

This project is a simple telemetry dashboard system that I developed using ESP32.

In this project, ESP32 generates fake flight data and sends it to a web dashboard over WiFi. The main goal was to display altitude, speed and battery values on the dashboard. I also added a low battery LED warning system.

While developing the project, I tried to improve my understanding of ESP32 web server systems, telemetry logic, GPIO control and basic IoT communication. I tested different ideas during development and improved the warning system step by step.

The project is currently developed in a simulation environment because I do not yet have access to all physical hardware components. Even so, I focused on understanding and applying real system logic.

## Features

- Fake flight data generation
- Altitude, speed and battery monitoring
- ESP32 web server system
- Low battery warning
- LED alert system
- GPIO control

 # ESP32 Drone Telemetry Dashboard

Bu proje, ESP32 kullanılarak geliştirdiğim basit bir telemetry dashboard çalışmasıdır.

Projede ESP32 üzerinden sahte uçuş verileri üretilip WiFi aracılığıyla web paneline gönderildi. Dashboard kısmında altitude, speed ve battery değerlerini göstermeyi amaçladım. Ayrıca düşük pil durumunda çalışan bir LED warning sistemi de eklendi.

Projeyi geliştirirken ESP32 web server yapısını, GPIO kontrolünü, telemetry mantığını ve temel IoT haberleşmesini öğrenmeye çalıştım. Bazı bölümlerde farklı denemeler yaparak sistemi geliştirdim ve warning sistemi ekledim.

Çalışmalar şu anda simülasyon ortamında yapılıyor çünkü tüm fiziksel donanım bileşenlerine erişimim bulunmuyor. Buna rağmen gerçek sistem mantığını anlamaya ve uygulamaya odaklandım.

## Features

- Fake flight data generation
- Altitude, speed and battery monitoring
- ESP32 web server system
- Low battery warning
- LED alert system
- GPIO control
